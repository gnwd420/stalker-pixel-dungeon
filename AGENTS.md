# Постоянные инструкции проекта

## 1. Проект

- Название проекта: Stalker Pixel Dungeon.
- Основа: Shattered Pixel Dungeon 3.3.8.
- Базовый commit: `7b8b845a76fe76c6b7c031ae9e570852411f56db`.
- Целевая платформа первой версии: Windows desktop.
- Рабочая ветка: `develop`.
- Ветка `upstream-v3.3.8-base` является неизменяемой контрольной веткой и используется только для сравнения с исходной базой.

## 2. Концепция

- Мир строится как одна общая процедурная карта Зоны.
- Переходы через двери ведут в отдельные ограниченные локации.
- Основные типы интерьеров: дом, гараж, завод, база, лаборатория и бункер.
- Безопасные зоны: бар, магазин и база.
- Первая игровая версия сосредоточена на оружии, броне и расходниках.

## 3. Правила разработки

- Делать небольшие изолированные изменения.
- Не смешивать несколько этапов дорожной карты в одном изменении.
- Не изменять ветки `master` и `upstream-v3.3.8-base`.
- Не выполнять commit или push без прямой команды пользователя.
- Не запускать `:desktop:debug` без разрешения оператора.
- После изменений предлагать оператору compile-проверку `:desktop:classes`.
- Не исправлять посторонние предупреждения исходного проекта вне текущего этапа.
- Сохранять совместимость с Windows и Java 21.
- Не изменять Android/iOS без необходимости текущего этапа.

## 4. Лицензия и контент

- Соблюдать GNU GPLv3.
- Сохранять авторские уведомления и credits Shattered Pixel Dungeon.
- Мод должен иметь отдельное название и отдельный package/application ID.
- Использовать только оригинальные либо явно разрешённые графику, звук и тексты.
- Не копировать проприетарные ресурсы, логотипы или сюжетные материалы других игр.
- Стилистика должна быть самостоятельной постапокалиптической интерпретацией.

## 5. Проверки

- Основная compile-проверка Windows:

  ```powershell
  .\gradlew.bat :desktop:classes --no-daemon --console=plain
  ```

- Запуск игры выполняется оператором:

  ```powershell
  .\gradlew.bat :desktop:debug --no-daemon --console=plain
  ```

- Рабочее дерево до начала задания должно быть чистым.
- Codex сообщает точный список изменённых файлов.
